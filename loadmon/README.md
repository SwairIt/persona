# loadmon — монитор нагрузки ПК и локальных моделей

Отдельный самодостаточный сервис: видит нагрузку компьютера (CPU/RAM/GPU/VRAM/темп.)
и локальных моделей (Ollama), пишет историю, отдаёт API и дашборд. Persona дергает
его API для индикатора нагрузки в чате (при локальной модели).

## Запуск

```bash
# из корня проекта, в venv где стоят fastapi/uvicorn/psutil/httpx
python -m loadmon
# → http://127.0.0.1:8770  (дашборд)
```

Переменные окружения:
- `LOADMON_PORT` — порт (деф. 8770)
- `LOADMON_INTERVAL` — период сэмплинга в секундах (деф. 3)
- `LOADMON_DB` — путь к SQLite (деф. `loadmon/loadmon.db`)
- `OLLAMA_HOST` — адрес Ollama (деф. `http://127.0.0.1:11434`)

## API

- `GET /api/load/now` — мгновенный снимок (CPU/RAM/GPU/VRAM + загруженные модели Ollama)
- `GET /api/load/history?minutes=10` — история сэмплов
- `GET /api/models` — агрегаты по моделям из событий генерации + оптимизационная пометка
- `POST /api/load/event` — Persona шлёт сюда метрики генерации:
  `{model, provider, prompt_tokens, output_tokens, elapsed_ms, vram_used_mb}` → считает ток/с
- `GET /api/health`, `GET /` — здоровье и дашборд

## Что меряется

- **CPU/RAM** — `psutil` (есть всегда).
- **GPU/VRAM/темп./мощность** — `nvidia-smi` (драйвер NVIDIA). На ПК без NVIDIA
  (напр. этот dev-сервер) поля = `null`, сервис не падает. На твоём ПК с **GTX 1050 Ti**
  драйвер кладёт `nvidia-smi` в `System32` — поля заполнятся автоматически.
- **Загруженные модели** — Ollama `GET /api/ps` (какая модель в памяти, сколько VRAM,
  доля на GPU). Если Ollama не запущен — пусто.
- **«Как думает» модель** — реалистично это live ток/с во время генерации + всплеск
  GPU/VRAM (не «активность нейронов»). Ток/с приходят из событий Persona.

## Оптимизация

`/api/models` помечает модель «медленно», если средняя скорость < 8 ток/с — это почти
всегда признак, что модель **не влезла в VRAM целиком** (partial offload в RAM). Лечение:
взять модель меньше / квант Q4_K_M. На 1050 Ti (4 ГБ) комфортно 1.5–3B Q4.

## Интеграция с Persona

Persona (порт 8000) при локальной модели показывает в чате индикатор; при наведении
тянет `GET http://127.0.0.1:8770/api/load/now` (CORS открыт) и показывает CPU/GPU/VRAM.
После каждой генерации Persona может слать `POST /api/load/event` с токенами/латентностью.
