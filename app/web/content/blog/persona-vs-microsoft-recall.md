Microsoft Recall — самая известная попытка большой компании сделать «фотографическую память» для компьютера: система периодически снимает экран, чтобы вы могли потом найти всё, что видели. Идея ровно та же, что у Persona. Но дьявол — в архитектуре: кто пишет код, на каком железе это работает, что именно записывается и кому в итоге доверяют данные. Сравним честно, по пунктам, без передёргиваний.

## Что такое Recall

Recall — функция Windows для устройств класса **Copilot+ PC**: ПК с нейропроцессором (NPU) определённой производительности. Recall делает снимки экрана, индексирует их локально и позволяет искать по этой истории на естественном языке. После запуска функция пережила громкую критику за безопасность хранения и приватность, после чего Microsoft переработала её — сделала опциональной, добавила шифрование и аутентификацию. Это закрытая часть операционной системы.

## Пять различий, которые решают

**1. Кто держит систему.** Recall — часть Windows: свою копию не поднимешь, данные лежат по правилам платформы, остаётся доверять. Persona ставится на ваше железо: захват, база и индекс живут на вашей машине, и вы можете держать собственный экземпляр, не завися от чужого сервера. Оговоримся честно: репозиторий Persona сейчас закрыт и публичной лицензии у проекта нет — поэтому аргумента «прочитайте код и проверьте» мы не приводим. Разница не в аудите исходников, а в том, у кого физически лежат данные и кто может выдернуть рубильник. Почему это принципиально — разбирали в статье про [приватность как архитектуру, а не обещание](/blog/open-source-protiv-pogloshcheniya).

**2. Привязка к железу.** Recall требует Copilot+ PC с NPU — это новые устройства определённого класса. Старый ноутбук или десктоп без NPU не подойдёт. Persona кроссплатформенна (Mac + Windows) и **не требует NPU** — работает на обычном железе, которое у вас уже есть.

**3. Что записывается.** Recall пишет **только экран**. Persona пишет экран **и звук** (с расшифровкой) — то есть охватывает и встречи, и разговоры, а не только то, что было видно на дисплее.

**4. Что сверху захвата.** Recall — это поиск по снимкам. Persona добавляет поверх захвата целый слой ассистента: [чат с памятью](/blog/chat-s-pamyatyu-bitemporal), [граф памяти](/blog/graf-pamyati), [голосовой доступ](/blog/golosovoy-dostup-k-pamyati), брифинги и напоминания, и даже [свою дообученную модель](/blog/svoya-model-fine-tune). Это разница между «искалкой по скриншотам» и «вторым мозгом».

**5. Чья экосистема.** Recall живёт внутри Windows и его политик — вы принимаете правила платформы целиком. Persona — независимый local-first проект: данные у вас, и продукт по архитектуре не может однажды сменить условия над вашей головой.

## Сравнение

| | Microsoft Recall | Persona |
|---|---|---|
| Исходники | закрытые (часть Windows) | закрытые, публичной лицензии нет |
| Своя копия на своём железе | ✗ (функция ОС) | ✓ (self-host) |
| Железо | только Copilot+ PC с NPU | Mac + Windows, без NPU |
| Захват | только экран | экран + звук |
| Поиск по истории | ✓ | ✓ |
| Чат с памятью | ✗ | ✓ кросс-чат + bi-temporal |
| Граф памяти | ✗ | ✓ |
| Голос hands-free | ✗ | ✓ |
| Брифинги / напоминания | ✗ | ✓ |
| Своя модель | ✗ | ✓ |
| Данные локально | ✓ (на устройстве) | ✓ при self-host; на размещённой версии — на её сервере |

## Где Recall объективно удобнее

Будем честны и здесь. Recall встроен в Windows — не нужно ставить отдельное приложение, он интегрирован в систему и работает «из коробки» на поддерживаемом устройстве. Если у вас новый Copilot+ PC и достаточно простого поиска по экрану, Recall закрывает базовый сценарий без лишних движений. Это реальное удобство встроенного решения.

И ещё две честные оговорки про Persona. Первая: языковую модель вы подключаете сами — либо свою локальную Ollama, и тогда переписка никуда не уходит, либо ключ облачного провайдера (OpenRouter, Groq, DeepSeek, Anthropic, OpenAI, Gemini и другие), и тогда текст запросов уходит именно тому провайдеру, которого выбрали вы. Вторая: на размещённой версии persona.getdoday.ru стоит Яндекс.Метрика с вебвизором — она пишет поведение в интерфейсе. Если развернуть Persona у себя, счётчика нет: это один подключаемый шаблон. Recall в этом смысле проще — он вообще не веб-приложение.

## Кому что подойдёт

- **Есть Copilot+ PC, нужен только поиск по экрану, доверяете Microsoft** → Recall логичный встроенный выбор.
- **Хотите свою копию на своём железе (без NPU), экран + звук и полноценного ассистента (чат + граф + голос + своя модель), и чтобы данные не зависели от платформы** → это Persona.

## Вывод

Recall — заметный шаг: большая компания узаконила саму идею памяти компьютера. Но он привязан к новому железу с NPU, ограничен экраном и встроен в одну экосистему, которую нельзя вынести к себе. Persona берёт ту же идею и доводит до кроссплатформенного ассистента: экран и звук, чат, граф, голос и своя модель — поверх захвата. Где при этом живут данные, решаете вы: развернули Persona у себя и подключили локальную Ollama — всё остаётся на вашей машине; взяли размещённую версию с облачным ключом — запросы уходят выбранному вами провайдеру, и больше никуда. Выбирая «второй мозг», смотрите не на бренд, а на то, у кого в итоге окажутся данные и сколько продукта вы получаете поверх скриншотов.
