Если вы дошли до open-source альтернатив Rewind — у вас правильные приоритеты: контроль и приватность. screenpipe и OpenRecall — достойные проекты, и в чём-то они сильны. Но между «инструментом захвата» и «персональным ассистентом» есть разрыв, и важно понимать, где он. Сравним честно, без принижения.

## Что хорошо у open-source аналогов

- **screenpipe** (AGPL) — мощный движок захвата: экран + аудио, диаризация говорящих, локальное хранение в SQLite, подключение к LLM через MCP. Отличная основа, если вы готовы собирать пайплайн под себя.
- **OpenRecall** — простой локальный аналог Recall: скриншоты + поиск, кроссплатформенно, данные у вас.

Общий плюс — полный контроль и аудируемость. Это правильный фундамент.

## Где разрыв

Захват — это половина задачи. Дальше начинается «что с этим делать», и тут готовые open-source аналоги обычно оставляют вас один на один с сырыми данными:

- **Чат с памятью.** В screenpipe доступ к истории идёт через MCP/внешние клиенты; полноценного диалогового ассистента с кросс-чат recall и bi-temporal фактами из коробки нет. У OpenRecall — в основном поиск.
- **Граф памяти.** Связи между людьми, проектами и идеями поверх захвата — обычно отсутствуют.
- **Проактивность.** Утренние брифинги и напоминания из реального контекста — не часть базовых инструментов.
- **Голос.** Hands-free доступ к памяти — нет.
- **Своя модель.** Дообученная под вас «вторая копия» из коробки — нет.

Это не упрёк: проекты решают свою задачу — дать честный захват. Просто продукт «персональный ассистент» — это слой выше.

## Сравнение

| | screenpipe / OpenRecall | Persona |
|---|---|---|
| Захват экрана | ✓ (screenpipe + звук/диаризация) | ✓ Mac + Windows |
| Локально, данные у вас | ✓ | ✓ при self-host |
| Открытые исходники | ✓ (AGPL / open) | ✗ (репозиторий закрыт) |
| Чат с памятью | ~ через MCP / поиск | ✓ кросс-чат + bi-temporal |
| Граф памяти | ✗ | ✓ |
| Брифинги / напоминания | ✗ | ✓ |
| Голос hands-free | ✗ | ✓ |
| Своя дообученная модель | ✗ | ✓ |
| Шифрование «из коробки» | ~ (у OpenRecall нет) | есть инструменты приватности |

## Кому что подойдёт

- **Вам нужен движок и вы любите собирать сами** → screenpipe отличная база; стройте поверх него свой пайплайн.
- **Нужен минимальный локальный Recall** → OpenRecall закроет базовый сценарий.
- **Нужен готовый персональный ассистент** (захват + чат + граф + голос + брифинги + своя модель в одном, без сборки) → это Persona.

## Где Persona честно проигрывает

Раз уж сравниваем без принижения — то и без приукрашивания. У screenpipe и OpenRecall открытые исходники: их код можно прочитать, проверить и форкнуть, если проект свернёт не туда. **У Persona этого сейчас нет** — репозиторий закрыт, публичной лицензии у проекта нет, так что аргумент «проверьте сами» в нашу пользу не работает. Если аудируемость для вас критична, это весомый довод в сторону screenpipe.

Вторая честная оговорка — про модель. Persona не тащит с собой свою LLM: вы подключаете либо локальную Ollama, и тогда переписка не покидает вашу машину, либо ключ облачного провайдера, и тогда текст запросов уходит выбранному вами провайдеру. И третья: на размещённой версии persona.getdoday.ru стоит Яндекс.Метрика с вебвизором; при self-host её нет.

Главное, что роднит всех троих: захваченные данные остаются на вашей машине. Это правильный лагерь. Разница — в том, сколько продукта вы получаете поверх захвата, сколько готовы собрать руками и насколько вам важно иметь возможность прочитать код.
