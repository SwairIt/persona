    🚀 Подготовить установщик для Mac → {# === iPhone === #} {% elif device_kind == 'iphone' %}
    Важно: Apple физически запрещает приложениям делать скриншоты в фоне на iOS. Continuous capture как на Mac невозможен — это политика iOS, не баг Persona.

    Реальный способ — iOS Shortcuts (Команды):

    1. Зарегистрируй iPhone в /devices → скопируй device_token.
    2. В приложении Команды создай новый шорткат с действиями:
      • Сделать скриншот
      • Получить содержимое URL: {{ server_url }}/api/ingest/photo, метод POST, заголовок X-Device-Token = твой токен, тело форма с полем file = последний скриншот.
    3. Создай Личную автоматизацию «Время суток каждый час» → запускает шорткат. iOS будет показывать уведомление каждый раз (этого не обойти).

    Подробная инструкция со скриншотами — в /help, секция «Захват с iPhone».

    Альтернатива: iPhone как viewer

    Самый простой путь — не захватывать с iPhone вообще. Mac уже снимает всё, ты с iPhone просто смотришь через Safari. Это и быстрее и работает без танцев с шорткатами.
