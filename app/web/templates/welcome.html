    Persona на сервере умеет принимать скриншоты, но сами они делаются агентом на Mac. Без него лента будет пустая.

    Как поставить агент на Mac (3 шага)
    1. В терминале на Mac: 
      git clone https://github.com/SwairIt/persona ~/persona
cd ~/persona/mac-agent
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
    2. Создай config.json рядом с persona_agent.py: 
      {
  "server": {
    "url": "{{ server_url }}",
    "token": "<твой_admin_token>"
  }
}
    3. Запусти: python persona_agent.py

    ⚠️ admin token — это значение переменной PERSONA_ADMIN_TOKEN из .env на сервере. Это НЕ device_token из /devices.

    🚀 Самый простой путь — YandexGPT
    cloud.yandex.com → войти Яндекс-аккаунтом → создать API key → скопировать.
    Потом сюда:     /settings/llm → выбрать "YandexGPT" → вставить ключ → Save.

    🏠 Бесплатно навсегда — Ollama на твоём ПК
    Скачай ollama.com → ollama pull qwen2.5:3b → /settings/llm → "Локально через Ollama" → Save.
    Никаких ключей и регистраций.
    📍 Где взять Gemini-ключ конкретно
    1. Включи VPN (Gemini API заблокирован в РФ).
    2. Открой aistudio.google.com/apikey
    3. Войди Google-аккаунтом → Create API key → скопируй (начинается с AIza...).
    4. Сюда вставь: /settings/llm → выбрать "Google Gemini" → вставить ключ в поле под ним → Save.

    Если в РФ без VPN — лучше выбери YandexGPT/GigaChat/DeepSeek, они работают напрямую.
