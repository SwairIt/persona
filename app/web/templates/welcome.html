Welcome to Persona

Your personal memory layer. Captures your screen so you can search your past — what you read, wrote, watched, decided. Everything stays on your machine.

  1. 1.

    Press Start in the header

    Capture is paused by default. The pill in the top-right shows live state. Once you press Start, Persona takes a screenshot every {{ settings.capture_interval_seconds }} seconds.

  2. 2.

    Optional — enable OCR

    OCR turns on-screen text into searchable content. Without it, search still works on window titles and app names.

    {% if tesseract.available %} Tesseract detected — OCR ready ({{ tesseract.version }}) {% else %}
    How to install Tesseract on Windows
    1. Download from UB-Mannheim build
    2. Run installer with default options (path is C:\Program Files\Tesseract-OCR)
    3. Open .env in Persona's folder and add:
      PERSONA_TESSERACT_PATH=C:\Program Files\Tesseract-OCR\tesseract.exe
      PERSONA_OCR_ENABLED=true
    4. Restart Persona
    {% endif %}
  3. 3.

    Optional — plug in an LLM for AI summaries

    Add your own API key from Anthropic, OpenAI, or Groq to .env: 

    PERSONA_BYO_API_PROVIDER=anthropic
PERSONA_BYO_API_KEY=sk-ant-…

    Requests go directly from this app to the provider. Persona never sees your key or your data in the cloud.

  4. 4.

    Use Persona day-to-day

    • Timeline — browse your day, hour by hour
    • Search — find anything you saw
    • AI Summary — daily recap from your captures
    • Stats — top apps, dedup ratio, activity heatmap
    • Whitelist — exclude apps from capture (games, password managers)

    Press ? anywhere for keyboard shortcuts.
