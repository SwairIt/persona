🪟 Установка / обновление Windows-агента за один шаг

Откроет на твоём ПК: git clone + venv + установка зависимостей + автозапуск через Планировщик задач. Через ~30 секунд скрины начнут появляться в ленте.

🔄 Это же действие обновляет установленный агент: повторный запуск делает git pull, переписывает конфиг и перезапускает задачу. Запускай его всякий раз, когда видишь баннер «Доступно обновление».

🎙 Запись речи (всё что говоришь) — как включить

Поставь галочку «Записывать речь» у команды ниже — команда сама обновится (добавит $env:PERSONA_AGENT_VOICE='1'). Зависимости лёгкие (пара МБ, без 2 ГБ), расшифровка в текст — на сервере.

  • Нужен ffmpeg (кодирование звука) — установщик попробует поставить через winget install Gyan.FFmpeg.
  • Параметры → Конфиденциальность → Микрофон → разрешить классическим приложениям доступ.

Дальше — что делать после команды

✅ Токен вставлять никуда не надо — он уже внутри команды. Она пишет конфиг %APPDATA%\Persona\config.toml и регистрирует автозапуск.
  1. Если просили — разреши Микрофон: Параметры → Конфиденциальность и защита → Микрофон → «классические приложения».
  2. Проверь задачу автозапуска: Get-ScheduledTask PersonaAgent (или Планировщик задач → PersonaAgent).
  3. Через ~30 сек проверь /devices — Windows покажет «был только что».
  4. Скрины появятся в /timeline.
Ничего не появилось / агент не подключается
  • Лог: Get-Content "$env:LOCALAPPDATA\Persona\Logs\persona-agent.log" -Tail 40 -Wait
  • Адрес сервера в команде должен быть достижим с этого ПК (если агент на другой машине — нужен публичный URL).
  • Перезапуск задачи: Restart-ScheduledTask PersonaAgent (или Stop/Start).
  • Перегенерируй команду кнопкой ниже и запусти ещё раз — это безопасно (обновление на месте).

Что произойдёт

  1. Сервер создаст агент-токен (можно отозвать в /admin/agents).
  2. Я подготовлю одну команду PowerShell (irm ... | iex).
  3. Ты копируешь её, открываешь PowerShell, вставляешь.
  4. Скрипт делает git clone, ставит зависимости, прописывает автозапуск (Планировщик задач).
Не доверяю irm ... | iex

Скрипт можно посмотреть: после генерации открой URL {{ server_url }}/api/install/windows.ps1?t=... в браузере — увидишь весь PowerShell. Или вручную: git clone https://github.com/SwairIt/persona.git, затем powershell -ExecutionPolicy Bypass -File persona\mac-agent\install\install.ps1 -Server {{ server_url }} -Token <token>.
