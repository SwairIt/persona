Generates ~ screenshots spread across weekdays of the last calendar days (09:00–18:00 UTC), plus 30 notes, 5 hourly cards and 1 daily pin. Refuses if the screenshots table already has more than 50 real rows.

How it works

  • Every screenshot is tagged with is_demo = 1 (see migration 129_demo_data.sql) and gets an ocr_text prefixed with [DEMO].
  • Hourly cards and the daily pin are tagged via the same [DEMO] prefix on the summary / pin column — the purge query targets that prefix.
  • Timestamps are seeded from a fixed RNG seed so reruns produce an identical-looking gallery — convenient for reproducible screenshots.
  • Thumbnail paths are NULL — the seeder does not write any image files. The timeline renders the empty-thumb placeholder for demo rows.
