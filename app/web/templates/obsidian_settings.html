Obsidian-синхронизация

Persona записывает ежедневное summary, hourly-карточки, заметки и закреплённые скриншоты в виде markdown-файлов в выбранную папку Obsidian Vault. Синхронизация только запись — Persona не читает из vault и пересоздаёт файлы целиком на каждом цикле. Файл с тем же содержанием не перезаписывается (хэш-сравнение).

Vault path должен быть абсолютным и существующей директорией. Persona откажется сохранить путь, который ведёт внутрь её собственной data-папки или репозитория — иначе sync рискует перезаписать вашу базу данных.

Status

Vault

Persona будет писать в подпапку Persona/ внутри этого vault — по одному файлу на день (YYYY-MM-DD.md). Пустая строка отключает запись даже при включённой галке.

Окно "Run now"

Этим значением пользуется кнопка Run now ниже. Периодический воркер всегда смотрит на последние 14 дней — слайдер на эту константу не влияет, только на одноразовый запуск. Диапазон: {{ lookback_min }}–{{ lookback_max }} дней.
