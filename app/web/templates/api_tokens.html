Usage example

curl -H "Authorization: Bearer <your-token>" \
     http://127.0.0.1:8765/api/screenshots/recent

Scopes are enforced per-route via check_scope. Issue read-only tokens by default; add narrow write:* scopes only for the resources a client actually needs, and keep admin:bulk for trusted automation that mutates many records in one shot.
