Usage example

curl -H "Authorization: Bearer <your-token>" \
     http://127.0.0.1:8765/api/screenshots/recent

The scopes string is currently advisory — individual routes will start enforcing it in future versions. Issue read-only tokens by default and only upgrade to read,write when a specific client needs it.
