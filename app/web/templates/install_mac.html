🍎 Установка / обновление Mac-агента за один шаг

Откроет на твоём Mac: git clone + venv + установка зависимостей + автозапуск через launchd. Через 30 секунд скрины начнут появляться в ленте.

🔄 Это же действие обновляет уже установленный агент: повторный запуск делает git pull, переписывает конфиг (с токеном устройства для синхронизации кода) и перезапускает агент. Запускай его всякий раз, когда видишь баннер «Доступно обновление».

🎙 Запись речи (всё что говоришь) — как включить

Просто поставь галочку «Записывать речь» прямо у команды ниже — ничего отдельно вставлять не надо, команда сама обновится. Зависимости лёгкие (пара МБ, без 2 ГБ), расшифровка в текст делается на сервере.

Ещё один раз на Mac:

  • brew install ffmpeg (кодирование звука)
  • Системные настройки → Конфиденциальность → Микрофон → разрешить Terminal/Python

macOS покажет оранжевую точку микрофона когда пишет — это норма. Если хочешь чтобы расшифровка шла локально на Mac (а не на сервере) — это уже ~2 ГБ, скажи мне.

Дальше — что делать после команды

✅ Токен вставлять никуда не надо — он уже внутри этой команды. Она сама пишет конфиг ~/.config/persona-agent.toml с токенами устройства. Токен, который показывался на /devices при добавлении Mac, можно игнорировать — установщик выдал свежий.
  1. Разреши запись экрана: Системные настройки → Конфиденциальность и безопасность → Запись экрана → включи Terminal (или Python).
  2. Перезапусти агент после разрешения:
    launchctl kickstart -k gui/$(id -u)/com.swairit.persona-agent
  3. Через ~30 сек проверь /devices — Mac покажет «был только что», а жёлтый баннер обновления исчезнет.
  4. Скрины появятся в /timeline.
Ничего не появилось / Mac не подключается
  • Логи: tail -f ~/Library/Logs/persona-agent.err.log
  • Адрес сервера в команде должен быть не localhost — иначе Mac не достучится. Открывай эту страницу по публичному адресу (devtunnel).
  • Жив ли процесс: launchctl list | grep persona
  • Перегенерируй команду кнопкой ниже и запусти ещё раз — это безопасно (обновление на месте).

Что произойдёт

  1. Сервер создаст для тебя агент-токен (можно отозвать в /admin/agents).
  2. Я подготовлю одну команду curl ... | bash.
  3. Ты копируешь её, открываешь Терминал на Mac, вставляешь.
  4. Скрипт делает git clone, ставит зависимости, прописывает автозапуск.
Что если я не доверяю curl ... | bash

Понимаю. Скрипт можно посмотреть глазами: после генерации команды просто открой URL {{ server_url }}/api/install/mac.sh?t=... в браузере — увидишь весь Bash. Или сохрани его: curl -fsSL ... -o installer.sh && cat installer.sh, изучи, потом bash installer.sh.

Альтернатива — клонировать вручную: git clone https://github.com/SwairIt/persona.git ~/persona, потом ~/persona/mac-agent, создать venv, поставить requirements.txt, скопировать токен из /admin/agents в config.json.
