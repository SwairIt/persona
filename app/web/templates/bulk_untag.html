🏷 Bulk untag

Remove a tag from every screenshot whose full-text search query matches — the inverse of the v0.24 bulk_tag CLI helper. Non-destructive: only the screenshot_tags link rows are removed; the underlying screenshots and the tag itself stay put.

Heads up. Untagging is reversible — re-tagging is one FTS5 query away — but a runaway query (query=".") can still strip a tag off thousands of shots in one click. Always preview first to see the match count. The confirm button only appears after a preview, and the confirmation token is invalidated as soon as the tag, query, or match count changes.

Preview is always dry-run — no tag rows are touched yet.
