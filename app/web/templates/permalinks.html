Permalinks

Capture the current URL — path, query string, hash — as a short /go/<slug> link that 302-redirects to the original page state. Useful for sharing a heavily-filtered search, a focus session bookmark, or a long timeline range without pasting a 300-character URL into chat. Permalinks are relative-only: a target URL that does not start with / is rejected so this table cannot be turned into an open redirect.

Captures window.location.href (minus the origin), asks for an optional label, then copies the short link to your clipboard.

How it works

  • Slugs are 8-character base36 tokens (e.g. a3k8m1qr) drawn from secrets.randbelow — opaque, but stable.
  • The redirect is a 302 Found so the link is never cached as permanent — a future edit (if added) takes effect immediately.
  • Each /go/<slug> hit increments the hits counter so dead links surface in this table.
  • Target URLs must start with /. Absolute URLs and protocol-relative URLs (//…) are rejected.
