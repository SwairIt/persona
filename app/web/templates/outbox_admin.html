Webhook outbox

Готовые шаблоны исходящих запросов в Linear, Notion, Slack и любые свои URL. Подписанный конверт Persona сюда не отправляется: тело рендерится из body_template через str.format с полями события и POST-ится с вашим Authorization заголовком. Для собственных приёмников, которые умеют разбирать подписанный конверт, используйте обычные webhooks.

Доставка best-effort: одна попытка, без подписи. При ошибке (5xx, timeout) запись попадёт в webhook_retry_queue для диагностики, но повторно не отправится — модель ретраев у внешних сервисов отличается от нашей.
