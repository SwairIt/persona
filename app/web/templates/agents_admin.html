Endpoints

  • POST /api/agent/heartbeat — liveness probe
  • POST /api/agent/audio-segment — multipart audio upload (max 10 MB)
  • POST /api/agent/screenshot — multipart image upload (max 5 MB)
  • GET /api/agent/me — self-check

Every request must carry an Authorization: Bearer <token> header. Successful requests update the agent’s last_seen_at (and the channel-specific last_audio_at / last_screen_at columns) so the table above shows fresh activity.
