API токены

Read-only Bearer-токены для внешних инструментов, которые читают данные Persona через /api/v1/*. Persona хранит только SHA-256-хеш — plaintext-значение показывается один раз на странице выдачи. Заголовок: Authorization: Bearer <token>.

Пример использования

curl -H "Authorization: Bearer <token>" \
     http://127.0.0.1:8765/api/v1/screenshots.json

Машинно-читаемый список выданных токенов (без хешей) доступен на GET /api/api-tokens.json — пригодится для дашбордов инвентаризации, не показывает plaintext ни одного токена.
