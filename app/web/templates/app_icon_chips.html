Иконки приложений

Лёгкие фавиконки (символ + цвет) для визуальной идентификации приложений в плотных списках. Каждая строка хранится в таблице app_icon_chip. Источник bundled — захардкоженный пресет из BUNDLED_ICONS, fallback — детерминированная первая буква + цвет из хеша имени, user — ручной выбор оператора. Оставьте символ пустым, чтобы откатиться к автогенерации.
