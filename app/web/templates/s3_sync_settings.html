S3-синхронизация

Раз в сутки Persona заливает зашифрованный snapshot SQLite и свежие миниатюры в S3-совместимый bucket (AWS S3, Cloudflare R2, Backblaze B2, MinIO). Синхронизация — write-only, Persona никогда ничего не читает обратно. Все файлы шифруются локально (Fernet, ключ выводится из вашей passphrase) до того, как покинут машину.

Зависимости: для работы нужны Python-пакеты boto3 и cryptography. В будущем релизе они переедут в опциональный extra [s3] — пока установите их вручную (uv add boto3 cryptography), иначе вкладка молча отдаст status=missing_dep.

Расписание

По умолчанию 3 (3 часа ночи) — вне пиков захвата экранов. Выберите час, когда машина включена и интернет стабилен.

Bucket

Подпапка внутри bucket — удобно для нескольких машин, которые пишут в один общий bucket (например, laptop-01/ и desktop/). Без слэшей — Persona добавит их сама.

Для AWS S3 оставьте пустым — boto3 сам подберёт регион. Для Cloudflare R2 / Backblaze B2 / MinIO — вставьте URL endpoint'а из их UI.

Учётные данные

Persona никогда не возвращает сохранённый секрет обратно в форму. Пустое поле = «не менять». Чтобы стереть, очистите bucket-имя — sync отключится по missing_config.

Запишите её отдельно — без неё восстановить snapshot из bucket невозможно. Persona никогда не отправляет её наружу и не восстанавливает по запросу.

Использует уже сохранённые поля. Сохраните форму перед нажатием, иначе будут использованы предыдущие значения.

Где взять bucket

  • Cloudflare R2 — бесплатный egress, 10 GB free tier. Гайд по R2 API tokens.
  • Backblaze B2 — $0.005/GB/мес. Документация S3-совместимого API.
  • MinIO — self-hosted на VPS, нулевая стоимость передачи между домашними машинами. Установка.
  • AWS S3 — оставьте поле endpoint пустым; создайте IAM-пользователя с правом s3:PutObject только на ваш bucket.
