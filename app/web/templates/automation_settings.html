Автоматизация — браузер и MCP

Управление двумя системами автоматизации чата: интерактивным браузер-агентом (постоянный Chromium на сессию — кликает, вводит текст, читает, делает скрины между ходами) и MCP-рантаймом (запуск внешних MCP-серверов по stdio и подключение их инструментов как mcp__сервер__инструмент). Локальная сеть (localhost / 127.0.0.1 / RFC1918) для браузера запрещена всегда.

Домены браузера (allow / deny)

По одному домену на строку (или через запятую). Allow пустой = разрешены любые публичные сайты. Deny важнее allow. example.com покрывает и www.example.com.

MCP-рантайм (stdio)

Запускать внешние MCP-серверы из /admin/mcp (включённые, не-builtin, с разрешённой командой запуска: npx / node / uvx / python / deno / bun) и подключать их инструменты в чат.
