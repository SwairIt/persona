{# Focus-aware notification bell widget (v1.44). Served by ``GET /widget/notification-bell`` (see :mod:`app.web.routes.notifications`) and embedded via HTMX (``
``) on any host page that wants the bell — typically the dashboard header. Context contract ---------------- * ``widget_id`` — short random hex string injected by the route so multiple bells on one page can coexist without DOM-id clashes. Behaviour --------- * On render: GETs ``/api/notifications/unseen.json`` once for the initial badge state, then opens an ``EventSource`` to ``/api/notifications/stream`` for live updates. * Click on the bell toggles a collapsible list. * Click on a single list row marks just that one as read and removes it locally (server is the source of truth — we refetch the count on the next stream tick to reconcile). * "Clear all" sweeps the badge via POST ``/all-seen``. Styling ------- The widget uses plain CSS classes (``notif-bell-…``) defined inline so the partial renders consistently whether or not the host page loaded Tailwind. The dimensions are conservative — bell sits in a header, the panel anchors top-right and is ~320px wide. #}
