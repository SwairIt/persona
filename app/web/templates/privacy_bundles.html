Privacy bundles

Группы подстрочных шаблонов, по которым capture-loop работает в режиме privacy mode: ни скриншота, ни строки метаданных, только хешированная запись о пропуске. v1.43 — поверх жёстко зашитого защитного списка теперь можно вешать собственные «пресеты» под банки / менеджеры паролей / крипту / dating / mental-health, или редактировать руками. Hard-coded шаблоны остаются как back-compat «пол» — выключить их через UI нельзя, это сознательно.

Как это работает

Шаблоны бандла объединяются с зашитым PRIVACY_PATTERNS и компилируются в кэш по SHA-256-фингерпринту отсортированного списка (см. app/privacy_mode.py). Capture-loop сверяет активное окно с этим набором подстрочно, без учёта регистра. При совпадении скриншот не делается, в privacy_skip_event пишется только первые 16 hex SHA-256 от заголовка и сам шаблон, который сработал. Любая правка через эту страницу сбрасывает компиляционный кэш — следующий кадр капчер-цикла увидит новый список.
