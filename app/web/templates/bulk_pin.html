📌 Bulk pin

Pin every screenshot matching a full-text search query — pinned shots are immune to the retention tier sweep and will not be demoted to warm/cold or aged out.

Heads up. Pinning is non-destructive but it overrides retention, so a runaway query can lock thousands of shots in storage forever. Always preview first to see the match count. The confirm button is only enabled after a preview, and the confirmation token is invalidated as soon as the query or match count changes.

Preview is always dry-run — nothing is pinned yet.
Un-pin by query

Drops every matching shot back to the hot tier so the regular sweep can handle it. No preview step — re-pinning is one form away.
