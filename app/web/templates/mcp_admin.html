🔌 MCP серверы

Model Context Protocol — стандарт Anthropic для подключения к моделям инструментов (файлы, шелл, гит, поиск). Здесь — реестр серверов.

{# --- STATUS BANNER --- #}

✨ Установка через чат

Можно просто сказать Persona в чате: «установи mcp …» — ИИ сам добавит сервер сюда и включит (инструмент install_mcp). Встроенные инструменты (файлы, шелл, git, веб, скиллы) работают уже сейчас.

  • Включай нужные серверы тумблером, правь команду запуска под свои пути
  • Внешним MCP-серверам обычно нужен Node.js + npm на машине
  • Запуск внешнего MCP-runtime (subprocess + JSON-RPC мост) — в работе
