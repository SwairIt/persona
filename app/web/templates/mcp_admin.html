⚠️ Готовность к запуску

Реестр серверов готов. Запуск MCP-runtime (subprocess + JSON-RPC мост) — следующий тик. Пока ты можешь:

  • Включить тех серверов которые тебе нужны (filesystem на D:\, git, brave-search)
  • Поправить команду запуска под свои пути (например, поменять D:\Projects на свой)
  • Установить Node.js + npm на машине (для большинства MCP-серверов нужны)

Когда я доделаю runtime — твои настройки сразу подхватятся.
