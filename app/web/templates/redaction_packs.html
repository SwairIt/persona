How it works

  • Installation uses INSERT … ON CONFLICT(name) DO NOTHING, so re-installing a pack only adds rules that are missing.
  • Each rule lands enabled. Pause or remove individual entries from the redaction admin.
  • Full machine-readable catalogue is available at /api/redaction-packs.json.
  • Patterns only mask OCR text before it is stored. The original screenshot image is never modified.
