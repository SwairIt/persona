{{ t('section_language') }}

Switch the UI language. Translation tables live under app/translations/{lang}.json; missing keys fall back to English so a partially translated locale still renders. Stored in kv_settings under ui_language.

{{ t('section_appearance') }}

Compact mode tightens row padding, shrinks the base font, and reduces the timeline / day-kanban thumbnail size. The setting is stored in kv_settings and applied via a data-compact attribute on <body>.

Grayscale mode wraps the whole UI in a CSS filter: grayscale(1) for distraction-light reading — accent colours, thumbnails, and tag pills collapse to neutral tones. Stored in kv_settings and applied via a data-grayscale attribute on <body>.

Reduce motion disables every CSS transition and animation across the UI — hover fades, status-pill pulses, htmx swap animations, Alpine transitions. Useful if you are sensitive to motion (vestibular disorders, post-concussion, migraine) or simply prefer a static interface. Stored in kv_settings and applied via a data-reduce-motion attribute on <body>.

Capture behaviour

As of v1.10 Persona starts capturing immediately when the app boots — the yellow Пауза pill on first frame routinely tricked new users into thinking Persona was broken. Enable the checkbox below if you would rather have the old behaviour where every fresh boot starts paused and you have to click Resume in the header before the first screenshot is taken. Stored in kv_settings under capture_paused_on_boot; read once by the FastAPI lifespan on process start, so the change applies on the next Persona restart (not immediately).
