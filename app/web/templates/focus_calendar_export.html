Calendar export

Download completed focus sessions as an .ics file. Import into Google Calendar / Apple Calendar / Outlook to overlay your deep-work blocks against regular meetings. Only sessions marked Done are exported — bailed-out blocks are skipped.

Pick a window

The default {{ default_days }} days covers a quarter of focus history. Pick a longer window for end-of-year review, or a shorter one to keep the import light.

{% for days in window_options %} Last {{ days }} days {% endfor %}

Tip: in Google Calendar use Settings → Import & export and upload the downloaded file into a dedicated “Persona focus” calendar so the events stay separate from your meeting schedule.

What ends up in each event

  • Title — the focus session label, or Focus session if you didn't set one.
  • Start & end — the actual UTC timestamps captured by the Pomodoro timer.
  • Description — work/break minutes and the session ID so you can cross-reference back to the dashboard.
