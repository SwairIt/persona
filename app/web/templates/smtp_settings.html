SMTP delivery

Mail your daily and weekly LLM digests to yourself via a SMTP relay you own (Gmail app password, Fastmail, your own Postfix, etc.). Delivery is opt-in — the toggle below is off by default and no message leaves this machine until you flip it.

Optional dependency: SMTP delivery requires aiosmtplib. If you have not installed it, run uv pip install aiosmtplib in the Persona checkout and restart the server. The "Send test" button will report missing_dep until then.
Settings are written to kv_settings and used by the daily & weekly digest jobs.
