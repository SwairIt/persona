OCR redaction

Regex patterns that mask sensitive text inside OCR output before it lands in the database or full-text index. Every match becomes ***, so emails, credit-card numbers, and tokens never surface in search. The screenshot image itself is never touched — only the searchable text representation.

How it works

  • Patterns run in stable insertion order after every OCR job.
  • Every match is replaced with ***.
  • Disabled rules are stored but skipped, so you can pause without losing the pattern.
  • Invalid regex are logged as redaction.bad_pattern and silently skipped — one broken rule cannot break the OCR worker.
  • Screenshots that were captured before a rule was added are not re-scanned.
