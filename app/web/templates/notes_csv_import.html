Notes CSV import

Bulk-import standalone markdown notes from a CSV file — handy for migrating off Evernote / Bear / Obsidian or rehydrating a fresh install from a previous export. The required column is body; optional columns are title, created_at (ISO-8601) and tags (comma-separated). The import is idempotent — re-uploading the same file is a no-op because each row is hashed against the existing notes.body column.

⚠

Limits & safety

  • Maximum upload size: {{ (max_upload_bytes // (1024 * 1024)) }} MiB.
  • UTF-8 encoded CSV only (Excel "CSV UTF-8" export works; legacy Windows-1252 will fail with a 400).
  • Encrypted notes are excluded from the hash dedup — a re-imported plaintext row that coincidentally matches an encrypted note's hidden body will produce a duplicate.
  • Every upload is recorded in the audit log under notes_csv_import.upload.
