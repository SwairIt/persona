Encrypted vault

Store API keys, webhook secrets and SMTP passwords encrypted with a master password you re-enter on every read. Each row uses its own salt + Fernet token; rotating one secret never touches the others. Persona never stores the master password — lose it and the rows are unrecoverable.

Optional dependency: the vault needs cryptography. If it is missing the read/write forms return missing_dep — install with uv pip install cryptography and restart the server.
