Feed tokens

Per-feed share tokens for Persona's /feeds/* RSS / Atom endpoints. Use the query string ?token=<token>. Each token is scoped to an fnmatch pattern so you can hand someone one feed without exposing the rest. Persona stores only the SHA-256 hash — the raw value is shown exactly once below, right after you issue it.

Usage example

http://127.0.0.1:8765/feeds/tags/cooking.rss?token=<your-token>

The feed_pattern is matched against the request path with fnmatch, so /feeds/tags/*.rss covers every tag feed without giving the holder access to /feeds/journal.rss.
