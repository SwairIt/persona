Import from URL

Fetches a backup JSON from a remote http(s) URL and applies it in merge mode (additive — existing rows are kept). Handy for syncing preferences across machines: point each instance at the same private gist or internal share, then re-trigger the import after edits. Capped at 1 MiB with a 5 second timeout.
