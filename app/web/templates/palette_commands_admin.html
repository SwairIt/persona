Palette colon-commands

Vim-style command mode for the Cmd+K palette. When the input starts with :, the palette flips from fuzzy-search to command-mode — Enter then dispatches the action via POST /api/palette/command instead of navigating.

Enable command-mode

The JS hook ships as /static/palette_command_mode.js and is not loaded by base.html. Pick one of the opt-in paths below.

Option A — per-session via DevTools

const s = document.createElement("script");
s.src = "/static/palette_command_mode.js";
document.head.appendChild(s);

Lives until the page reloads. Useful for trying the feature without editing templates.

Option B — persistent via a custom page

Add the snippet to any template that already extends base.html — for example a bookmarklet-style settings sub-page. Avoid editing base.html directly so the activation stays opt-in. 

<script src="/static/palette_command_mode.js" defer></script>

Try it from the CLI

curl -sX POST http://127.0.0.1:8000/api/palette/command \
  -H 'Content-Type: application/json' \
  -d '{"input": ":help"}'

The same endpoint the JS hook posts to — useful for smoke tests after a deploy.
