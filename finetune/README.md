# «Вторая копия» — персональная локальная модель (QLoRA на GTX 1050 Ti)

Дообучаем маленькую open-weight модель в ТВОЁМ тоне (тёплый прямой друг,
по-русски, на твоей стороне), чтобы она крутилась локально и приватно на
твоём ПК с 1050 Ti.

## Честно про ожидания (важно)

- **1050 Ti = 4 ГБ VRAM, Pascal** (нет bf16, нет flash-attn). Реально дообучается
  модель **0.5–1.5B** в 4-bit (QLoRA). Не 7B+, не «с нуля».
- Это **клон СТИЛЯ/характера**, а не клон интеллекта. Маленькая модель будет
  тёплой, «твоей» по тону и норм в простом общении, но **рассуждать/искать/
  пользоваться инструментами** как большая модель — не будет. Для сложного держи
  рядом мощную модель и переключайся в `/settings/llm`.
- Брат на 1060 обучал **CNN для дорог/парковок** — это другой (компьютерное
  зрение, миллионы параметров) и куда легче класс задач, чем LLM. Не путать.

## Шаги

```bash
# 1) датасет (стиль + опц. твоя история чатов)
python scripts/build_persona_dataset.py --out finetune/data/persona.jsonl --size 400
#   персонально под себя (история + факты из памяти):
python scripts/build_persona_dataset.py --out finetune/data/persona.jsonl \
    --size 300 --include-history --user-id <твой_id>

# 2) обучение (отдельное окружение, тяжёлые пакеты)
pip install -r finetune/requirements.txt
python finetune/train_qlora.py --data finetune/data/persona.jsonl \
    --val finetune/data/persona.val.jsonl \
    --model Qwen/Qwen2.5-1.5B-Instruct --out finetune/out/persona-lora
#   OOM на 4 ГБ? → --model Qwen/Qwen2.5-0.5B-Instruct --max-seq 512

# 3) экспорт в GGUF + Ollama — см. export_gguf.md
# 4) подключить в /settings/llm (provider=ollama, model=persona-mini)
```

## Если 4 ГБ не хватает / слишком медленно

Обучи тем же `train_qlora.py` на **бесплатном Google Colab T4 (16 ГБ)** — там
влезет и 1.5B комфортно, и даже 3B. Затем скачай адаптер, слей, сконвертируй в
GGUF Q4_K_M и запускай локально на 1050 Ti (инференс 1.5–3B в Q4 в 4 ГБ
помещается). Тренировка — в облаке, жизнь модели — у тебя.

## Сколько данных

- Старт: 300–800 примеров (синтетика стиля). Норм для «характера».
- Сильнее/персональнее: добавь свою реальную историю чатов (`--include-history`).
  Чем больше живых диалогов в твоём тоне — тем точнее клон.
