# Persona — дорожная карта «лучше всех конкурентов»

> Живой план. Источник конкретных задач — параллельный аудит (workflow
> `persona-full-audit`) + конкурентный ресёрч. Исполняется волнами; каждая волна =
> один или несколько workflow + прямые правки, с тестами и деплоем на каждом срезе.
> Пуш: SwairIt → `SwairIt/persona` (private). Версия бампается на каждый фич-коммит.

## Где мы (2026-06-30, v2.20.87)
- Hosted-модель: Pro/триал-юзер заходит на сайт → онбординг → чат-ассистент на
  LLM владельца, со своей изолированной памятью (чат/память уже scoped по user_id).
- Гейт пускает не-владельца только в /chat + /onboarding; личные данные владельца закрыты.
- Биллинг: триал 3 дня + ручной грант Pro; чекаут ЮKassa — заглушка (ждёт креды).
- Лендинг/pricing — обновлены под триал/Pro.

## Принципы
1. **Не ломать прод.** Каждый срез: import-check + pytest + smoke → коммит → деплой.
2. **Изоляция данных свята.** Любая новая фича для не-владельца — только своё (user_id).
3. **Ценность > объём.** Сначала быстрые победы (high value / low risk / small effort).
4. **Конкурентный паритет, потом превосходство.**

## Волны (приоритет сверху вниз)

### Волна 1 — Ассистент уровня ChatGPT/Claude (ядро продукта)
Чат — это то, что Pro-юзер видит каждый день. Должен быть не хуже топов:
- Грациозный офлайн-LLM: понятное состояние «ассистент офлайн», а не голая ошибка.
- Паритет UX: регенерация ответа, редактирование своего сообщения, копирование,
  стоп-генерация, аккуратный рендер код-блоков с кнопкой copy, markdown, пустые состояния.
- Надёжный стриминг + обработка ошибок провайдера (таймаут, 429, отвал сети).

### Волна 2 — Память как киллер-фича (наш главный отрыв)
Конкуренты забывают — мы помним. Доводим до блеска:
- Качество recall (релевантность, отсутствие протечек, дедуп).
- Управление памятью для юзера: что ассистент о нём знает, удалить/закрепить.
- Видимость: «ассистент вспомнил X» в чате.

### Волна 3 — Биллинг и конверсия (деньги)
- Чекаут ЮKassa (когда будут креды): первый платёж + рекуррент + вебхук.
- Грейс-период, отмена подписки, dunning, понятный экран истечения триала.
- Лендинг/онбординг под конверсию.

### Волна 4 — Надёжность и охват
- Безопасность (rate-limit, дыры), производительность (индексы, N+1).
- Мобильная адаптивность + доступность ключевых экранов.
- i18n-паритет, починка битых ссылок, пустые состояния везде.
- Тесты на критичные пути.

### Волна 5 — Превосходство над конкурентами
Конкретные фичи из конкурентного ресёрча, которых нет у других (заполняется из аудита).
