# Биллинг Persona — план (монетизация)

> Решение от 2026-06-24. Подробности по коду — пакет `app/billing/`, память `billing-model`.

## Модель: self-host + Pro-лицензия (НЕ мульти-тенант)
Данные захвата/памяти в Persona **общие** (не разделены по юзерам — см. docstring
`app/auth/owner.py`). Пускать чужих на один сайт нельзя — увидят чужой экран. Поэтому:
- **Магазин** (`persona.getdoday.ru`): продаёт подписку через ЮKassa и выдаёт `license_key`.
- **Клиент** (чужой self-host): вставляет ключ → его инстанс валидирует ключ по API
  магазина → включает Pro. `kv billing_role` = `store` (деф.) | `client`.
- Мульти-тенант SaaS **отклонён** (потребовал бы `user_id` во все таблицы + ~300 роутов).

## Тарифы (по конкурентам: ChatGPT/Claude $20, GigaChat 600 ₽, Yandex Plus 449 ₽)
- **Free** — 0 ₽. Приватность/локальность не гейтим (это позиционирование).
- **Pro** — **690 ₽/мес** или **5 900 ₽/год** (−29%). Гейтим масштаб/интеллект:
  вектор/гибрид recall, ночная рефлексия, граф памяти, своя модель, мультидевайс,
  история без лимита (free — 30 дней).

## Провайдер: ЮKassa, продавец — самозанятый
- ⚠️ ЮKassa с **29.12.2025** не выбивает чеки самозанятым → `receipt` НЕ шлём; чек НПД
  владелец регистрирует сам в «Мой налог» / через ФНС-НПД API. Списание карты и чек — раздельно.
- Рекуррента-планов в ЮKassa нет: наш планировщик списывает по сохранённому `payment_method_id`.
- Вебхук: подписи нет → проверка по IP-allowlist + повторный GET платежа; идемпотентность.
- Секреты ЮKassa — в env или `{PERSONA_DATA_DIR}/billing_secrets.json` (не в БД/git).
