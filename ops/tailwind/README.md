# Сборка Tailwind

`app/web/static/vendor/tailwind-built.css` — это **артефакт сборки**, он лежит
в репозитории намеренно: на боевом боксе нет node, и деплой не должен от него
зависеть.

## Зачем это появилось

До версии 2.36.0 каждая страница подключала `vendor/tailwind-play.js` — 407 КБ
JIT-компилятора Tailwind, причём **без `defer`**, то есть блокирующего разбор
документа. Браузер скачивал его, парсил, обходил DOM и генерировал CSS заново
на КАЖДОЙ загрузке, включая переходы по кабинету с тёплым кэшем.

Замер на сервере (Chromium, тёплый кэш, без сетевой задержки, страница `/chat`):

| | FCP | DOMContentLoaded | load |
|---|---|---|---|
| как было | 1320 мс | 2092 мс | 2105 мс |
| с заблокированным `tailwind-play.js` | 884 мс | 1496 мс | 1501 мс |

На телефоне и на медленной сети разрыв кратно больше: там 407 КБ ещё и едут по
сети, а JIT крутится на слабом CPU. Собранный CSS — 96 КБ (~24 КБ в gzip),
не блокирует парсер дольше одного запроса и кэшируется на год.

## Как пересобрать

Нужен node. Из корня репозитория:

```bash
npm install --no-save tailwindcss@3.4.17
npx tailwindcss -c tailwind.config.js -i ops/tailwind/input.css \
    -o app/web/static/vendor/tailwind-built.css --minify
```

Версия зафиксирована (`3.4.17`) — ровно та, что была вшита в Play-CDN, чтобы
набор утилит не поехал.

## Когда пересобирать — ОБЯЗАТЕЛЬНО

**Каждый раз, когда в шаблоне или в JS появляется Tailwind-класс, которого там
раньше не было.** Play-CDN генерировал классы на лету и прощал забывчивость;
сборка сканирует файлы заранее (`content` в `tailwind.config.js`) и знает
только то, что нашла. Не пересобрал — класс молча не применится.

Страховка от этого — `tests/test_tailwind_build_is_current.py`: он собирает
список классов из шаблонов и проверяет, что они есть в собранном CSS. Тест
падает ровно в том случае, когда сборку забыли обновить.

Чего сборка **не** увидит: классы, которых нет в исходниках как целых строк —
`'bg-' + color`, `class="text-{{ tone }}-500"`. На момент перевода (2.36.0)
таких в проекте не было. Если понадобится — либо писать классы целиком
(`{% if tone == 'warn' %}text-amber-500{% else %}text-zinc-500{% endif %}`),
либо заносить их в `safelist` конфига.
